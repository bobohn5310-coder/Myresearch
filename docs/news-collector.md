# 국내 연구소식 자동 수집

매일 새벽(한국시간) GitHub Actions 가 공개 RSS 에서 국내 연구 소식을 모아 Supabase `news` 테이블에 넣습니다. 사이트의 **국내연구소식** 화면에 자동으로 나타납니다.

## 소스

| 소스 | 내용 |
| --- | --- |
| 정책브리핑 과학기술정보통신부 보도자료 RSS | 정부 R&D·과학기술 정책 소식 |
| 헬로디디, 사이언스타임즈, 동아사이언스 RSS | 과학 전문 매체의 국내 연구 기사 |
| 구글 뉴스 검색 RSS | "교수 연구팀 개발", "반도체 연구팀" 같은 검색어로 여러 언론사의 연구 성과 기사 |

- 연구와 관계없는 기사는 "연구·개발·교수·논문" 같은 단어로 걸러냅니다.
- 제목과 요약의 단어로 분야(이공계, 생명/의학, AI/컴퓨터, 에너지, 양자/통신)와 태그를 자동으로 붙입니다.
- 같은 기사가 여러 언론사에 실리면 하나만 남깁니다.
- **저작권:** 기사 본문과 이미지는 저장하지 않습니다. 제목, RSS 가 공개한 짧은 요약(160자 이내), 출처, 원문 링크만 저장하고 "원문 기사 보러가기"로 원래 사이트에 연결합니다.

## 동작 구조

1. 매일 03:10 (KST) GitHub Actions 가 소식을 모아 `data/news.json` 을 커밋합니다.
2. 매일 03:40 (KST) Supabase 안의 예약 작업(pg_cron)이 `public.sync_news()` 를 실행해 새 소식을 `news` 에 추가합니다.
3. 자동으로 들어온 소식은 30일 뒤 지워집니다. 관리자가 직접 등록한 소식, "주요 소식"으로 표시한 소식은 지우지 않습니다.
4. 이미 들어온 소식을 관리자 화면에서 고치면, 다음 수집 때 덮어쓰지 않습니다.

DB 쪽 설정은 [`supabase/news_collector.sql`](../supabase/news_collector.sql) 에 있습니다. 처음 한 번 SQL Editor 에서 실행해야 합니다.
지금 바로 반영하려면 SQL Editor 에서 `select public.sync_news();` 를 실행하세요.

## 소스나 검색어 바꾸기

`scripts/collect_news.py` 위쪽의 `DIRECT_FEEDS`(RSS 주소)와 `GOOGLE_QUERIES`(검색어), `FIELD_RULES`(분야 분류 단어)를 고치면 됩니다.

## 로컬 실행

```bash
python scripts/collect_news.py --out data/news.json
```
