# 운영자 등록 연구실 (클로버 지수)

회원이 처음 클로버를 남길 때만 연구실이 생기던 것을, 운영자가 공개된 연구실 정보를 미리 넣어 둘 수 있게 했습니다.

## 어떻게 동작하나요
- 연구실 표(`clover_labs`)에 `source` 칸이 생겼어요. 회원이 만든 연구실은 `member`, 운영자가 넣은 연구실은 `admin` 입니다.
- 회원이 클로버를 남길 때 **같은 학교 + 같은 지도교수님 성함**을 적으면, 새 연구실을 만들지 않고 운영자가 넣어 둔 연구실로 이어집니다 (기존 묶기 규칙 그대로).
- 공개 화면은 바뀌지 않아요. 운영자 등록 연구실도 승인된 클로버가 생기기 전에는 목록에 안 나오고, 이름·분야는 지금처럼 6명이 모여야 보입니다.
- 홈페이지·확인한 페이지·대표 논문·과제는 관리자만 봅니다. 관리자 화면 '클로버 현황'에 `운영자 등록` 표시와 필터가 생겼어요.

## 넣는 순서 (Supabase → SQL Editor)
1. `supabase/clover_admin_labs.sql` — 칸·표 추가 (한 번만)
2. `supabase/seed_clover_labs_semiconductor_2026-11.sql` — 반도체 분야 시범 수집분

둘 다 여러 번 실행해도 안전합니다. 되돌리는 방법은 2번 파일 맨 위에 적어 두었어요.

## 수집 원칙
- 연구실 단위 공개 정보만: 학교·학과·연구실 이름·교수님 성함·연구 분야·홈페이지
- 개인 연락처(메일·전화·연구실 위치)와 학생·구성원 정보는 수집하지 않음
- 대표 논문은 학교/연구실 페이지에서 교수님을 확인한 뒤, 공개 서지정보(OpenAlex)에서 소속과 연구 주제가 맞는 저자 기록으로 교차 확인한 것만
- 연구 과제는 연구실과 확실히 맞는 것만 넣기로 했고, 이번 시범에서는 확인된 것이 없어 비워 둠
- 연구실 정식 이름이 페이지에 없으면 홈페이지 주소 약칭(예: DTFL 연구실)이나 연구 분야로 만든 가칭(이름 끝에 '(가칭)')을 씀. 교수님 성함은 공개되지 않는 칸이라 연구실 이름에 넣지 않음
